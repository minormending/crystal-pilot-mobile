How this works

The pilot reads the game's own memory through the symbol file — your party, the map you are on, and the collision data behind it — so it can plan a route and pick a move rather than guess from the picture.

Speed only changes how fast the game runs while you are watching it. A pilot task always runs as fast as the phone manages, which is the whole point of it.

What this is

An auto-pilot for Pokémon Crystal that runs entirely in this browser tab. Tell it to grind a Pokémon to a level and it plays the battles itself; tap the screen and it walks there.

It works by reading the game rather than watching the picture, which is what the second file is for.

What you need

  • .gbcthe ROM — the game itself
  • .symthe symbol file — the map of where things live in memory

Both come out of a pokecrystal build: run make and you get the pair.

Neither file leaves your phone. They are read in the page and never uploaded, which is also why this can be hosted publicly — no game data is served, only the app.

Play

Press and hold to walk — a tap in a new direction only turns you.
Keyboard: arrows, Z/X for A/B, Enter for Start, Shift for Select.

Hunt & catch

Both walk the grass and run from everything else. Hunt hands you the battle; catch throws balls at it and counts them out of the bag. Only what this route has at this hour is offered.
